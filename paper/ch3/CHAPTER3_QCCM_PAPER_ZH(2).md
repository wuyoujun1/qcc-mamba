## 3 QCCM: Quantum Cross-Variable Coupling Module

### 3.1 模块总览

多变量时间序列预测中，预测视界越长，单变量自身历史所能提供的信息越有限，越需要借助变量间关系为远期预测补充额外信息。因此，跨变量耦合是长时序预测的重要信息来源。然而，现有主干网络以双向状态空间扫描隐式建模变量间关系，以 S-Mamba 为例，其对跨变量输入扰动的实测灵敏度约为 10⁻⁶，表明耦合信息在主干表征中实际缺失。为此，本文提出量子跨变量耦合模块 QCCM，显式度量变量间耦合，输出可解释的跨变量耦合矩阵。

图 X 给出 QCCM 的整体结构。模块以原始序列 x 与主干隐状态 H 为输入，经频域对齐、QCC 编码与量子核三个环节得到耦合矩阵。频域对齐将每个变量的原始序列变换为对齐频谱 S，消除时移与周期尺度等环境差异，使耦合度量只刻画变量间的结构关系；QCC 编码以主干隐状态 H 驱动振幅、以对齐频谱 S 驱动相位，将两者统一编码为各变量的 5-qubit 量子态 |ψ_v⟩ ∈ ℂ^32；量子核将量子态经量子电路调制后，以保真度度量变量两两之间的耦合强度，输出耦合矩阵 K ∈ ℝ^(V×V)：

```
K[i,j] = |⟨ψ_i|ψ_j⟩|²                            (3.1-1)
```

其中 ⟨·|·⟩ 为 ℂ^32 上的标准内积，ψ_i 为变量 i 的量子态。K 为逐样本自适应的跨变量耦合矩阵，对角恒为 1、元素取值于 [0,1]，刻画任意两变量的耦合强度。

该矩阵的可解释性体现在两个层面。其一，K 是可读的 V×V 耦合矩阵，任意两变量的耦合强度可直接读取，经热力图即可识别强耦合变量对，而非隐没于黑盒权重中。其二，K 可进一步因子分解为内容相似度与谱相位相干之积；当某对变量耦合低时，可归因于内容相似度偏低或谱相位相干偏低，将单一数值转化为可解释的归因。两层可解释性共同构成 QCCM 输出的含义。

### 3.2 频域对齐与量子编码

本节构造 QCCM 的前两个环节。3.2.1 通过频域对齐将原始序列变换为对齐频谱特征 S，消除跨变量的时移与尺度差异；3.2.2 提出 QCC 编码，将主干隐状态与对齐频谱编码为量子态。

#### 3.2.1 频域对齐

不同变量的波形普遍存在两类环境差异：时移与周期尺度。时移指结构相同的波形在采样起点上的系统性错位，周期尺度指不同变量主导周期的差异。若不消除，模式相同的变量将在原始表示下被误判为不相关，污染耦合度量。为此，频域对齐以确定性变换消除两类差异；该变换不参与梯度更新，输出维度与输入长度 L 无关。

具体地，对每个变量 x_v ∈ ℝ^L 施加实数快速傅里叶变换 rFFT，得复谱 X_v(f) ∈ ℂ^(L/2+1)，其中 f = 0,1,…,L/2 为频率索引。为分别刻画各频率分量的强度与时间位置，定义幅度谱与相位谱。

**幅度谱**。

```
A_v(f) = |X_v(f)|
```

A_v(f) 刻画频率 f 分量的强度；尺度变化只移动幅度谱的主峰位置，频率轴对齐依赖 A。

**相位谱**。

```
φ_v(f) = arg X_v(f)
```

φ_v(f) 刻画频率 f 分量在时间轴上的起始位置；时移只改变相位谱，时间轴对齐依赖 φ。

**时间轴对齐**。由时移定理，波形整体时移 δ 等价于相位谱叠加斜率为 2πδ 的线性项。令 δ̂_v 为变量 v 相对各变量共同时间基准的时移估计，由归一化互相关的最优滞后给出。消除该线性项：

```
φ̃_v(f) = φ_v(f) − 2πf·δ̂_v                          (3.2-1)
```

对齐后相位谱斜率归零，仅保留波形形状信息。

**频率轴对齐**。令 f̂_peak(v) = argmax_f A_v(f) 为幅度谱主频，对应主导周期。由尺度定理，时间尺度差异表现为频率轴的缩放，据此归一化频率坐标：

```
f̃ = f / f̂_peak                                      (3.2-2)
```

使所有变量的主峰对齐至同一频率位置，消除主导周期差异。

**重采样**。在对齐后的统一频率坐标上取 M = 32 个均匀采样点并作线性插值，得重采样幅度谱 Ã_v ∈ ℝ^M 与重采样相位谱 φ̃_v ∈ ℝ^M，拼接为对齐频谱：

```
S_v = [ Ã_v ; φ̃_v ] ∈ ℝ^(2M) = ℝ^64                (3.2-3)
```

由时移定理与尺度定理可知，对齐频谱 S_v 对时移与时间尺度变换保持不变，维度恒为 2M，与输入长度 L 无关。至此频域对齐完成，对齐频谱 S 作为 QCC 编码的相位通道输入，将频域信息作为上下文注入量子编码。

#### 3.2.2 QCC 编码

为将内容与上下文统一编码进量子态，本文提出 QCC 编码。变量 v 的主干隐状态 h_v ∈ ℝ^d 作为内容驱动**振幅通道**，对齐频谱 s_v := S_v ∈ ℝ^(2M) 作为上下文驱动**相位通道**。

**振幅通道**。设 W_r ∈ ℝ^(32×d) 为振幅投影矩阵，令：

```
p(h_v) = softmax(W_r·h_v) ∈ ℝ^32                    (3.2-4)
```

p(h_v) 为 32 维概率分布，分量非负且和为 1，决定各计算基态被选中的概率。

**相位通道**。设 W_θ ∈ ℝ^(32×2M) 为相位投影矩阵，令：

```
θ(s_v) = W_θ·s_v ∈ ℝ^32                             (3.2-5)
```

θ(s_v) 的各分量给出对应计算基态的相对相位。

**定义 1**。记 b ∈ {0,1}⁵ 为 5 比特字符串，|b⟩ 为对应的计算基态，构成 ℂ^32 的规范正交基，p_b(h_v) 与 θ_b(s_v) 分别为 p 与 θ 的第 b 个分量。变量 v 的量子态定义为：

```
|ψ_v⟩ = Σ_{b∈{0,1}⁵} √p_b(h_v) · e^(i·θ_b(s_v)) · |b⟩          (3.2-6)
```

由 Σ_b p_b(h_v) = 1 立得 ‖ψ_v‖² = 1，编码自动归一。复振幅 z_b := √p_b·e^(i·θ_b) 的振幅由 h 决定、相位由 s 决定，两路来源分工明确；h 与 s 仅在核的内积处发生交互。至此，每个变量都被编码为量子态 |ψ_v⟩，为下一节核计算做好准备。

### 3.3 量子核与核因子化

基于 3.2 构造的量子态 |ψ_v⟩ ∈ ℂ^32，本节完成 QCCM 的第三环节。3.3.1 计算两两量子态的保真度核；3.3.2 将核因子分解为内容相似度与谱相位相干之积，使耦合矩阵可解释、可诊断。

#### 3.3.1 保真度核

QCC 编码 (3.2-6) 将主干隐状态 H 与对齐频谱 S 的特征编码为量子态，该量子态继而通过由 RY-RZ 旋转层与 CNOT 纠缠门交替堆叠构成的量子电路。各变量在同一电路结构下完成变换，旋转层调整单比特的振幅与相位，纠缠层建立比特间的关联，电路可编译至量子硬件。

基于通过量子电路的量子态，由式 (3.1-1) 定义的保真度核可直接计算变量 i、j 的耦合强度 K[i,j] = |⟨ψ_i|ψ_j⟩|²，即两量子态的重叠度。保真度核刻画两量子态的相关性：两态越接近，核越接近 1；越趋于正交，核越接近 0；对角元素恒为 1。由此得到矩阵 K_raw ∈ ℝ^(V×V)，即式 (3.1-1) 中耦合矩阵 K 的原始形式，未作任何归一化。

#### 3.3.2 核因子化

上述保真度核虽可直接计算，但单值输出无法揭示耦合高低的成因，故将其分解为内容与相位两个因子。

**内容相似度**。定义 Bhattacharyya 系数

```
B(h_i, h_j) := Σ_b √(p_b(h_i)·p_b(h_j))
```

其中 p 为振幅通道 (3.2-4) 输出的概率分布。B 度量两变量内容分布的重叠程度，分布一致时取最大值 1，互不重叠时取 0。其平方 B² 构成核的内容因子，仅依赖于振幅通道 H。

**谱相位相干**。令 ω_b := √(p_b(h_i)·p_b(h_j)) 为内容重叠权重，μ_b := ω_b/B 为归一化权重，满足 Σ_b μ_b = 1，定义谱相位相干

```
M_ij := Σ_b μ_b · e^(i·Δθ_b)                            (3.3-1)
```

其中 Δθ_b := θ_b(s_i) − θ_b(s_j) 为两变量在基态 b 上的相位差。M_ij 为相位差复指数按内容重叠权重的加权平均，由于权重归一化，|M_ij| ≤ 1，仅当所有相位差一致时才取等号，相位差分散时随之减小。其平方 |M_ij|² 构成核的相位因子，该因子的相位差由相位通道 S 决定，权重由振幅通道 H 决定。

**因子分解**。由 (3.1-1) 与上述定义可直接推导

```
K[i,j] = B(h_i,h_j)² · |M_ij|²                          (3.3-2)
```

即耦合强度等于内容相似度与谱相位相干之积。该分解与 QCC 编码的设计一致：内容因子 B 仅取决于振幅通道 H，相位因子 |M| 的相位差由相位通道 S 决定并按内容重叠加权，两条通道在核中相乘。据此，耦合矩阵每个元素都可归因于内容或相位因子，某对变量耦合低时，可判断是 B² 偏低还是 |M_ij|² 偏低，使耦合矩阵具备诊断能力。同时，|M_ij| ≤ 1 保证相位通道只能抑制而不能增强内容相似度，相位失配会使耦合消失，这正是频域对齐对耦合度量至关重要的原因。

综上，QCCM 以原始序列与主干隐状态为输入，经频域对齐、量子编码与保真度核三个环节输出可解释的耦合矩阵；该矩阵既可直接读取与可视化，也可因子分解以诊断耦合低的原因。接入下游主干前，该矩阵进一步行归一化，即去掉对角、温度缩放与 softmax，作为跨变量消息混合的权重，细节见第四章 QCCK-M。
