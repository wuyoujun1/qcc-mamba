# 师姐 Reback 批注 + 用户写作总则（核心收敛版）

> 命名基线：本章方法 **QCCK**、编码 **QCCE**、度量环节 **量子核**；正文不出现 QCCM（QCCM/Module 语义只留给第四章"层实例 QCCK Layer"这种工程组件）。

---

## ⚠️ 先于一切：语法红线 + AI 发散禁令（用户反复强调，任何一句都要过）

**A. 用英文的逻辑写中文（中文 = 英文直译底稿），否则后面翻译很乱：**
1. 句子要有**主语 + 谓语 + 宾语**；找不到主语就用"**我们**"。
2. 补充说明用**非限定定语从句**（"该…/其…/which…"），不把"…的…的…"定语堆在名词前。
3. **句子和句子之间要有逻辑**，连接词写显式（为了…/随后/经…演化后/从而/使…能够）；两句没逻辑就并成一句，不靠逗号硬拼。
4. 句首禁"这些/那些/上述/这种"当孤指（译文 = dangling 的 these/those）。
5. 反例：`这些量子态经…调制后送入量子核。` → 英文 `These quantum states, after… are fed…` 的 these 指谁？读者茫然。正例：`各变量的量子态经该线路演化，得到纠缠量子态，作为量子核的输入。`
6. **正文零破折号、零括号**：破折号与一切括注内联改写进句子；缩写内联写（"…编码 QCCE"，不写（QCCE））。唯一放行：纯数学符号自带的括号与公式编号引用（p(h_v)、式 (3.1-1)），那是符号不是叙述。

**B. AI 发散禁令（AI 的四个病，逐条不许犯）：**
1. **凭空**：凭空蹦出一个组件/步骤/句子，无出处、无关联 → 每个新东西必须能指回前文或模型定义（为什么用→由什么组成→起什么作用）。
2. **造术语**：学术没有的说法不许用（"量子电路调制"✗ → "量子态经参数化量子线路演化/幺正演化"✓）。
3. **不准确**：科学主张（目的、机制、门种类）拿不准就**问用户，不许猜**，要跟自己提出的模型扣得上。
4. **发散**：不主动引入对话里没出现过的概念，宁可少给不凭空多给。

**C. 16 条批注里方法论级核心 = 下表的 T1–T6；其余批注（没主语/全称缩写/首句总起/同层同构/写细/两句无逻辑）本质就是上面 A/B 的红线实例，被 A/B 覆盖，不单列。**

## 核心六条 → 六个模板

| | 批注要点 | 模板 | 一句话实例 |
|---|---------|------|-----------|
| T1 | **C5 成分定位**：X 作为 Y 的什么组成成分，由什么组成，起什么作用 | `X 作为 Y 的（成分），由（…）组成，起到（…）作用。` | `频域对齐作为 QCCK 的输入处理环节，由谱变换与时间轴/频率轴两级对齐构成，消除时移与周期尺度差异。` |
| T2 | **C7 方法核心**：X 作为核心，由什么组成，通过什么方式，得到什么，最终实现什么 | `X 作为 Y 的核心，由（…）组成，通过（…），得到（…），最终实现（…）。` | `QCCE 作为 QCCK 的核心，由振幅/相位通道组成，通过把 H、S 编码为振幅与相位，得到各变量初始量子态，实现内容与上下文统一编码。` |
| T3 | **C8 前后环节关系**：X 作为 Y 的什么环节，把经 Z 得到的量子态做什么处理，得到什么，有什么用（核↔编码 就靠这条） | `X 作为 Y 的（环节），以经 Z 得到的（量子态）为输入，做（处理），得到（产物），该产物（有什么性质/用）。` | `量子核作为 QCCK 的耦合度量环节，以 QCCE 编码并演化得到的纠缠态 |ψ_i⟩ 为输入，计算保真度 |⟨ψ_i|ψ_j⟩|²，输出 K，供读取/可视化并作主干混合权重。` |
| T4 | **C11 定义句**（英文逻辑）：我们定义了 A 与 B，as shown in 公式，which 分别刻画… | `我们定义了 A 与 B（如式…），二者分别刻画（…）。` | `我们定义了幅度谱与相位谱（如式…），which 分别刻画各频率分量的强度与时间位置。` |
| T5 | **C13 目的先行**：为解决什么问题，我们定义 A 与 B，其中 A 是什么、B 是什么、二者起什么作用 | `为（解决问题），我们定义了 A 与 B：A 是（…），B 是（…），二者（起…作用）。` | `为把内容(H)与上下文(S)统一编码进量子态，我们定义了振幅通道与相位通道：振幅通道把 H 映射为概率分布、决定各基态振幅；相位通道把 S 映射为各基态相位。` |
| T6 | **C3+C4 产物交代**：给性质（回指公式可核验）+ 好处一句话 | 产物后紧跟：`（性质），（好处，一句话）` | `K 对角恒 1、取值 [0,1]、逐样本自适应；该可解释性使耦合可读、可诊断。` |

**命名观（C1，独立一条，非模板）**：提"方法"的章/节不用 Module，用 **Kernel / Encoding**——Module 是工程组件词（`nn.Module`、Transformer module），强调的是接口；Kernel/Encoding 是方法词，强调的是数学对象与性质。K 是 fidelity kernel（可引 quantum kernel 一脉：Havlíček et al., Nature 2019），编码是 amplitude/phase encoding（QML 惯例）。组件语义留给第四章的 QCCK Layer。

## 写作总公式（把六条收成一条，写任何方法句都照此填空）

`为了（目的）→ 我们（动作，有主语）→ 定义/设计（对象，全称+缩写）→ 对象由（什么）组成 → 量子态/数据经它（做什么，标准术语）→ 得到（产物，给性质）→ 产物（有什么用，一句话）。`

每节首句总起、末句铺垫下一节；同层句子同构（同 T 模板换槽位）；不凭空、不造词、不飘指代、与自己的推导（K=B²·|M|²）扣得上。
