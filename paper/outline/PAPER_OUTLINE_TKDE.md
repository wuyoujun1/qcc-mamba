### 3 QCCM: Quantum Cross-Variable Coupling Module

> 第三章完整正文（中文版，自 `CHAPTER3_QCCM_PAPER_ZH.md` 嵌入；公式编号 3.1-1 ~ 3.3-4；待办：图号替换"图 X"、定理详证入附录、英文化）

#### 3.1 Module Overview

多变量时间序列预测中，跨变量耦合（cross-variable coupling）是长时序预测的关键信息来源：当预测长度增大时，单变量自身的历史信息趋于耗尽，预测质量愈发依赖于对变量间相互影响关系的正确刻画。然而，现有主干网络（如 S-Mamba）以双向状态空间扫描隐式建模变量间关系，其实测预测输出对跨变量输入的灵敏度接近为零（约 10⁻⁶），表明耦合信息在主干表征中实际缺失、未被有效利用。为此，本文提出**量子跨变量耦合模块**（Quantum Cross-Variable Coupling Module, QCCM）：以主干隐状态 H 与原始序列 x 为输入，经频域对齐与量子编码构造每个变量的量子态，并用量子核显式度量变量间耦合度，输出可解释的跨变量耦合矩阵。

图 X 给出了 QCCM 的整体架构，其由三个环节串行构成：（i）**频域对齐**（3.2.1）将原始序列 x 变换为对齐频谱 S ∈ ℝ^(B×V×64)，消除时移与周期尺度等环境差异，使后续的耦合度量仅刻画变量的结构性关系；（ii）**相位-振幅接口**（Phase–Amplitude Interface, PAI，3.2.2）将主干隐状态 H 与对齐频谱 S 编码为 5-qubit 量子态 |ψ_v⟩ ∈ ℂ^32，其中 H 经 softmax 投影决定各计算基态的振幅（内容），S 经相位投影决定基态间的相对相位（上下文）；（iii）**量子核**（3.3）以保真度核度量变量两两之间的耦合强度，输出耦合矩阵 K ∈ ℝ^(V×V)：

```
K[i,j] = |⟨ψ_i|ψ_j⟩|²                            (3.1-1)
```

其中 ⟨·|·⟩ 为 ℂ^32 上的标准内积，ψ_i 为变量 i 的量子态（构造见 3.2.2）。K 为逐样本自适应的跨变量耦合矩阵：对角元素恒为 1，元素值域为 [0,1]，刻画任意两变量之间的耦合强度。该矩阵可直接可视化解释，并作为耦合度量输出供下游跨变量消息混合使用（见第四章 QCCK-M）。三个环节的详细构造分别于 3.2 与 3.3 中给出。

#### 3.2 Frequency-Domain Alignment and Quantum Encoding

本节构造 QCCM 的前两个环节。3.2.1 通过频域对齐将原始序列变换为对齐频谱特征 S，消除跨变量的时移与尺度差异；3.2.2 提出相位-振幅接口（PAI），将主干隐状态与对齐频谱编码为量子态。

##### 3.2.1 Frequency-Domain Alignment

不同变量的波形普遍存在两类环境差异：**时移**（sampling-start offset）与**周期尺度**（dominant-period scale）。时移指两个模式相同的变量在采样起点上存在错位（例如同一负荷曲线的峰值分别出现在上午十点与下午两点）；周期尺度指不同变量的主导周期不同（例如日周期与周周期）。若不加以消除，上述环境差异将使"模式相同"的变量在原始表示下被误判为不相关，从而污染跨变量耦合度量。为此，频域对齐以确定性变换（全程不参与梯度更新）消除两类差异，且其输出与输入长度 L 无关。

具体地，对每个变量 x_v ∈ ℝ^L 施加实数快速傅里叶变换（rFFT），得复谱 X_v(f) ∈ ℂ^(L/2+1)，其中 f = 0,1,…,L/2 为频率索引。幅度谱与相位谱分别定义为

```
A_v(f) = |X_v(f)|        （幅度谱，各频率成分强度）
φ_v(f) = arg X_v(f)      （相位谱，各频率成分初相）
```

**时间轴对齐（相位去趋势）**。由时移定理，波形整体时移 δ 等价于相位谱叠加斜率为 2πδ 的线性项。令 δ̂_v 为变量 v 相对其余变量共识时钟（leave-one-out 均值）的时移量估计，由归一化互相关的最优滞后给出。消除该线性项：

```
φ̃_v(f) = φ_v(f) − 2πf·δ̂_v                          (3.2-1)
```

对齐后相位谱斜率归零，仅保留波形形状信息。

**频率轴对齐（主频归一化）**。令 f̂_peak(v) = argmax_f A_v(f) 为幅度谱主频（对应主导周期）。由尺度定理，时间尺度差异表现为频率轴的缩放；据此归一化频率坐标：

```
f̃ = f / f̂_peak                                      (3.2-2)
```

使所有变量的主峰对齐至同一频率位置，消除主导周期差异。

**重采样**。在对齐后的统一频率坐标上取 M = 32 个均匀采样点并作线性插值，得重采样幅度谱 Ã_v ∈ ℝ^M 与重采样相位谱 φ̃_v ∈ ℝ^M，拼接为对齐频谱：

```
S_v = [ Ã_v ; φ̃_v ] ∈ ℝ^(2M) = ℝ^64                (3.2-3)
```

**性质 1（对齐频谱的不变性）**。由时移定理与尺度定理，对齐频谱 S_v 对时移变换与时间尺度变换均不变，且与输入长度 L 无关。证明思路：时移仅改变相位谱的线性项，已由 (3.2-1) 消除；尺度变换已由 (3.2-2) 归一化；重采样点数为固定值 M，故 S 的维度与 L 无关。

##### 3.2.2 Phase–Amplitude Interface (PAI)

为将内容与上下文统一编码进量子态，本文提出**相位-振幅接口**（PAI）。具体而言，变量 v 的主干隐状态 h_v ∈ ℝ^d 作为内容驱动**振幅通道**，对齐频谱 s_v := S_v ∈ ℝ^(2M) 作为上下文驱动**相位通道**。

**振幅通道**。设 W_r ∈ ℝ^(32×d) 为振幅投影矩阵，令：

```
p(h_v) = softmax(W_r·h_v) ∈ ℝ^32                    (3.2-4)
```

p(h_v) 为 32 维概率分布（分量非负且和为 1），决定各计算基态被选中的概率。

**相位通道**。设 W_θ ∈ ℝ^(32×2M) 为相位投影矩阵（其列向量为可学习频率），令：

```
θ(s_v) = W_θ·s_v ∈ ℝ^32                             (3.2-5)
```

θ(s_v) 的各分量给出对应计算基态的相对相位。

**定义 1（PAI 编码）**。记 b ∈ {0,1}⁵ 为 5 比特字符串，|b⟩ 为对应的计算基态（构成 ℂ^32 的规范正交基），p_b(h_v) 与 θ_b(s_v) 分别为 p 与 θ 的第 b 个分量。变量 v 的量子态定义为：

```
|ψ_v⟩ = Σ_{b∈{0,1}⁵} √p_b(h_v) · e^(i·θ_b(s_v)) · |b⟩          (3.2-6)
```

由 Σ_b p_b(h_v) = 1 立得 ‖ψ_v‖² = 1，即该编码自动归一。复振幅 z_b := √p_b·e^(i·θ_b) 呈现内容决定基态选取（√p_b）、上下文决定相对相位（e^(i·θ_b)）的非对称分工：h 与 s 仅在核的内积处发生交互。

**命题 1（电路可编译性）**。当振幅逐比特可分离、相位逐比特线性时，PAI 态 (3.2-6) 等价于单级乘积态电路：

```
|ψ_v⟩ = ⊗_{q=1}^5 RZ(η_q)·RY(α_q) |0⟩                (3.2-7)
```

其中 q = 1,…,5 为比特索引，α_q 为由振幅导出的旋转角（RY 构造振幅），η_q 为逐比特相位（RZ 赋予相对相位），RZ(·)、RY(·) 为绕 z、y 轴的单比特旋转门。证明思路：振幅逐比特可分离时 p(b) = Π_q a_q^{b_q}(1−a_q)^{1−b_q}，PAI 态分解为各比特态的张量积，每比特态 (√(1−a_q), √a_q·e^(i·η_q))ᵀ 恰为 RY(α_q)RZ(η_q)|0⟩ 的形式。实际计算中直接按 (3.2-6) 构造复向量，电路形式为理论等价物，便于未来量子硬件部署。

#### 3.3 Quantum Kernel and Kernel Factorization

基于 3.2 构造的量子态，本节定义量子核并推导其因子化结构。3.3.1 给出保真度核的定义与展开；3.3.2 证明核可因子化为内容相似度与谱相位相干之积，并讨论其性质；3.3.3 给出核的归一化输出。

##### 3.3.1 Fidelity Kernel

令变量 i、j 的量子态为 |ψ_i⟩、|ψ_j⟩（由 (3.2-6) 给出），保真度核矩阵 K_raw ∈ ℝ^(V×V) 按 (3.1-1) 定义。将 (3.2-6) 代入 (3.1-1)，记 ω_b := √(p_b(h_i)·p_b(h_j)) ≥ 0 与 Δθ_b := θ_b(s_i) − θ_b(s_j)，内积展开得：

```
K_raw[i,j] = |Σ_b ω_b · e^(i·Δθ_b)|² = C_ij² + S_ij²           (3.3-1)
C_ij = Σ_b ω_b·cos(Δθ_b)
S_ij = Σ_b ω_b·sin(Δθ_b)
```

其中 C_ij 为内容相似度加权的余弦项，S_ij 为谱相位对齐项。注意到 S_ij 关于 (i, j) 反对称（S_ij = −S_ji），即内积虚部携带方向信息（详见 3.3.2）。

##### 3.3.2 Kernel Factorization

**定理 1（核因子化）**。设 B(h_i, h_j) := Σ_b ω_b 为 Bhattacharyya 系数（内容相似度），μ_b := ω_b/B 为归一化权重（满足 Σ_b μ_b = 1），定义谱相位相干：

```
M_ij := Σ_b μ_b · e^(i·Δθ_b) ∈ ℂ                     (3.3-2)
```

则保真度核可因子化为：

```
K_raw[i,j] = B(h_i,h_j)² · |M_ij|²                   (3.3-3)
```

*证明*。由 (3.3-1)，⟨ψ_i|ψ_j⟩ = Σ_b ω_b·e^(i·Δθ_b) = B · Σ_b μ_b·e^(i·Δθ_b) = B·M_ij。两端取模平方即得 (3.3-3)。∎

由三角不等式 |M_ij| ≤ 1，得 K_raw[i,j] ≤ B(h_i,h_j)²，即相位通道仅能抑制内容相似度：当两变量频谱相位对准（|M_ij| → 1）时核保持满相似度；相位错开（|M_ij| → 0）时发生破坏性干涉，核趋近于零。

进一步地，虚部 S_ij = Im⟨ψ_i|ψ_j⟩ 在 i ↔ j 下反号，携带变量间系统化的领先-滞后（lead-lag）方向信息；实值经典核（如 RBF）恒实对称，无法表达该方向结构（该结论与复值嵌入模型通过虚部建模反对称关系的先例一致）。
