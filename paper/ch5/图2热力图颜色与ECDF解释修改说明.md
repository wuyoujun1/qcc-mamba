# 第五章图2修改说明（颜色与解释补充版）

## 1. 图2a / 图2b / 图2d 热力图颜色修改

### 当前问题

目前三张 coupling heatmap：

-   图2a：ETTh1 96
-   图2b：ETTm2 96
-   图2d：ETTh1 720

存在的问题：

1.  低耦合区域颜色过于集中：

    -   大量 0\~0.05 的元素接近同一种深色；
    -   读者难以区分弱耦合变量之间的差异。

2.  高值区域虽然突出，但中低值区域的信息利用不足。

3.  当前颜色容易让审稿人认为：

    -   大部分变量没有关系；
    -   只有少数几个亮点。

实际上 fidelity kernel 是连续 0\~1
的结构，需要展示整体分布，而不是只强调最大值。

------------------------------------------------------------------------

# 修改方案

## 保留原则

不改变真实数值：

\[
f\_{ij}=\|`\langle`{=tex}`\psi`{=tex}\_i\|`\psi`{=tex}\_j`\rangle`{=tex}\|\^2
\]

不进行：

-   softmax；
-   temperature scaling；
-   row normalization。

颜色只用于可视化。

------------------------------------------------------------------------

## 推荐修改

采用：

### 方案 A（推荐）

PowerNorm 非线性显示：

\[ color=f\^`\gamma`{=tex},`\quad `{=tex}`\gamma=0.5`{=tex} \]

作用：

-   保持单调关系；
-   不改变变量排序；
-   放大低值区域差异。

例如：

原始：

    0.01
    0.02
    0.04

颜色接近。

经过 gamma=0.5：

    0.10
    0.14
    0.20

视觉距离增大。

这样可以让弱耦合区域仍具有解释意义。

------------------------------------------------------------------------

## 颜色映射建议

避免：

-   黑色；
-   深紫色。

原因：

深色区域过多会降低可读性。

建议：

使用连续浅色渐变：

-   低值：浅蓝/浅灰；
-   中值：蓝绿；
-   高值：黄色。

要求：

0 附近不要接近黑色。

------------------------------------------------------------------------

## 数值标注

保留 cell 内数值：

原因：

颜色只是辅助。

真正可解释的信息来自：

\[ f\_{ij} \]

数值。

# 2. 图2c ECDF解释补充

## 当前问题

图2c展示：

ETTh1、ETTm2、ECL、Traffic

非对角 coupling value f 的累计分布。

但是正文没有解释 ECDF。

审稿人可能不知道：

-   横轴是什么；
-   纵轴是什么；
-   曲线差异代表什么。

------------------------------------------------------------------------

# 增加解释文字

建议加入：

> 为进一步比较不同数据集中的变量耦合分布，本文采用经验累计分布函数（Empirical
> Cumulative Distribution Function,
> ECDF）进行统计分析。对于每个数据集，我们收集平均保真度核 f
> 的所有非对角元素，并计算小于等于给定耦合强度阈值的变量对比例。横轴表示非对角耦合值
> f，纵轴表示累计比例。

------------------------------------------------------------------------

# ECDF含义解释

例如：

如果某条曲线快速上升：

说明：

-   大部分变量对具有较低耦合；
-   耦合结构更加稀疏。

如果曲线右移：

说明：

-   数据集中存在更多高强度变量关系。

------------------------------------------------------------------------

# 与QCCK解释关系

不要写：

"ECDF证明预测性能提升"。

正确：

> ECDF用于描述不同数据集变量关系复杂度，为后续耦合可解释性分析提供统计背景。
