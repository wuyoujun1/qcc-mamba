# 4 QCCK-M: Quantum Cross-Variable Coupling Kernel for Mamba

## 章首引言

第三章把变量间隐式传递的耦合显式度量成可解释的耦合矩阵 K。耦合度量本身不产生预测增益，只有嵌入主干、参与端到端训练，才能被下游利用。本章以 S-Mamba 为时序主干，把第三章的 QCCK 以 QCCK Layer 的形式嵌入主干每个编码器层之后，构成完整网络 QCCK-M，使每层变量表示都按显式度量的耦合融合其他变量的信息。4.1 给出整体结构总览，4.2 给出单个 QCCK Layer 的前向算法与网络训练细节。

## 4.1 QCCK-M 总览

第一句：图 X 给出 QCCK-M 的整体结构与数据流：输入的多变量时序数据经 RevIN 与 Tokenize 预处理，成为每个变量的 d 维表示 token；主干保留官方 S-Mamba 编码器逐层更新这些 token，并在每个编码器层之后由 QCCK Layer 按显式度量的耦合做一次跨变量混合；最后经预测头映射并反归一化，输出各变量的预测 Ŷ。

第二句：RevIN 与 Tokenize 是 QCCK-M 的输入预处理环节。RevIN 把每个变量沿时间轴减去均值、除以标准差，以缓解样本间的分布漂移；Tokenize 用一个线性层把每个变量的整段历史观测编码为一个 d 维的变量 token。变量 token 连同提供时间上下文的时间特征 token 一并作为主干输入。

第三句：主干是保留官方 S-Mamba 内部结构不变的时序编码网络，由逐层堆叠的编码器构成。每个编码器层更新变量 token，并在层末输出所有变量的隐状态 H∈ℝ^(B×V×d)。主干逐层深化每个变量的表示，但变量间的耦合仍主要经层内隐式传递，尚未被显式刻画与利用。为把显式度量的耦合用到每层表示上，QCCK-M 在每个编码器层之后引入第三章的 QCCK，以 QCCK Layer 的形式做一次显式跨变量混合。

第四句：QCCK Layer 以该层的隐状态 H 与对齐频谱 S 为输入，把各变量经 QCCE 编码成量子态，用保真度核度量变量两两之间的耦合，得到耦合矩阵 K，并将 K 行归一化为消息权重；每个变量据此聚合其他变量发送来的消息，以门控残差方式写回，得到融合了其他变量信息的更新隐状态 H′。QCCK Layer 只对变量 token 做混合，不涉及提供时间上下文的时间特征 token；对齐频谱 S 由频域对齐直接从输入计算得到，各层共用，为耦合度量提供频域上下文。由此，第三章显式度量的耦合真正参与每一层表示的更新。

第五句：预测头把每个变量的最终隐状态线性映射为长度等于预测长度的预测序列，经反归一化还原到原始尺度，得到各变量的预测 Ŷ。网络以时域误差与频域监督项之和为训练目标并端到端训练，损失的具体形式见 4.2。

第六句：综上，QCCK-M 在保留 S-Mamba 主干结构的前提下，把第三章的 QCCK 以 QCCK Layer 的形式嵌入每个编码器层之后，使可解释的耦合矩阵 K 成为跨变量消息混合的依据：K 既参与预测链路的运算，又可作为中间量被读取与检查，可解释输出由此接入预测链路。单个 QCCK Layer 的前向算法与网络训练细节见 4.2。

## 4.2 Algorithm of QCCK-M

第一句：每个编码器层之后嵌入的 QCCK Layer 结构相同、共用同一对齐频谱 S，整网的前向可由单层前向按层叠加理解，因此先给出单个 QCCK Layer 的前向算法，再说明其训练细节。

```
Algorithm 1: QCCK Layer 前向传播
输入：主干隐状态 H∈ℝ^(B×V×d)，对齐频谱 S∈ℝ^(B×V×2M)，超参数 N、T
输出：更新后的隐状态 H′，行归一化耦合矩阵 K_n
1: 对每个变量 v，由 QCCE 构造量子态，经两层的 U_v 演化得到 |ψ_v⟩
2: 计算保真度核 K[i,j] ← |⟨ψ_i|ψ_j⟩|²
3: 去对角与温度缩放：K ← (K − I)/T
4: 行归一化：K_n ← softmax(K)
5: 源、目标门控：K_n ← diag(g_tgt)·K_n·diag(g_src)
6: 消息投影：H_q ← H·W_q
7: 跨变量聚合：H_p ← K_n·H_q
8: 门控残差更新：H′ ← LN( H + γ·LN(H_p) )
9: return H′, K_n
```

第二句：第 1、2 步复用第三章的编码与耦合度量。每个变量 v 经第三章的 QCCE 编码成量子态 |ψ_v⟩：振幅通道由当前层隐状态 h_v 驱动、相位通道由对齐频谱 S_v 驱动，编码态再经两层参数化线路 U_v 演化；变量 i、j 的耦合强度取两态重叠度平方，即第三章式 (3.1-1) 的保真度核 K[i,j]=|⟨ψ_i|ψ_j⟩|²。K 对角元素恒为 1，其余元素在 [0,1] 上刻画各对变量耦合强度。

第三句：第 3、4 步把 K 变成可直接作权重的行归一化矩阵。K 对角恒为 1，若不处理会令每个变量与自身的消息权重最大，因此先减单位阵 I 去掉对角；再除以温度 T 缩放，T 越小 softmax 输出越集中；逐行 softmax 后每行和为 1，K_n 的每个元素表示相应源变量向该行目标变量发送消息的权重。

第四句：第 5 步引入两组可学习门控，缓解弱耦合、大变量数数据集上消息退化为全局平均的问题。K_n 的第 j 列决定源变量 j 向各目标发送的强度，第 i 行决定目标变量 i 从各源接收的强度；源门控 g_src 逐列缩放发送强度，目标门控 g_tgt 逐行缩放接收强度。

第五句：第 6 至 8 步完成消息聚合与写回。每个变量的表示先经可学习投影 W_q 映射为消息，再按 K_n 把各源消息加权聚合到每个目标，得到 H_p；聚合结果经层归一化、乘可学习门控标量 γ 后与变量自身表示相加，再整体层归一化，得到更新后的隐状态 H′。γ 初始取小值，使训练初期 QCCK Layer 近乎恒等映射、不破坏主干已有表示，随训练推进 γ 自适应增大、跨变量信息逐步融入各层。

第六句：单个 QCCK Layer 的开销为 O(V²·2^N)，只随变量数 V 与量子比特数 N 增长、与序列长度 L 无关，因而可逐层嵌入长序列主干。

第七句：网络端到端训练，目标为时域监督与频域监督之和 L = L_time + λ·L_FreDF。其中 L_time = ‖ŷ − y‖² 为时域均方误差，使预测逐点逼近真值；L_FreDF = |rFFT(ŷ) − rFFT(y)| 的均值为频域监督项，rFFT 为实数快速傅里叶变换，该项约束预测的频谱结构、恢复周期性与长程振荡成分；λ 为频域项权重。

第八句：行归一化的温度 T 控制 softmax 的集中程度，T 越小权重越集中于强耦合变量。不同预测视界下耦合核值的集中程度不同，因此 T 随视界自适应取值，具体数值见第五章实验设置；门控系数与 γ 随网络端到端优化，其前向位置见第 4、5 步。本章沿用官方 S-Mamba 的优化与训练流程，仅叠加上述目标与新增参数。

## 章末收尾

综上，第三章把隐式传递的变量耦合显式度量成可解释的 K；第四章在保留 S-Mamba 主干的前提下，把 K 作为每个编码器层之后 QCCK Layer 的消息混合权重接入预测链路，构成端到端网络 QCCK-M，并以频域监督约束长时程预测的频谱结构。第五章通过实验验证 QCCK-M 的预测精度、耦合机制与可解释性。
