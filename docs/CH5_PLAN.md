**④ C 节细节段**（补 5.3 的"怎么加扰动、响应怎么算"）
> 具体做法是：对第 j 个输入变量整体施加一个扰动，扰动幅度取该变量在样本内的时序标准差的 0.1 倍，正负号随机，每个变量重复三次以抵消随机性；记扰动前后的预测为 ŷ 与 ŷ′，则输出通道 i 对输入变量 j 的相对响应定义为 S[i,j] = ‖ŷ′_i − ŷ_i‖ / ‖ŷ_i‖，即该通道预测序列的变化幅度相对于自身预测幅度的比例，除以自身范数是为了让不同量级的变量可比。把 S 的对角元素平均得到对角响应，代表变量对自身的影响；把非对角元素平均得到非对角响应，代表变量对其它变量的影响；两者之比即跨变量影响相对于自身影响的强度。

> 依据：原始方法脚本 `/tmp/sensitivity_analysis.py`（ε=0.1σ、正负随机、重复 3 次、8 个测试样本）；模型 `bsl_ETTh1_96_s2024` / `qf2_ETTh1_96_q_base_s2024`，**与表 2 是同一批模型** ✓

### 6.2 结论：现在的表 7 测的不是"去掉耦合"

- **理论**：raw_k 下 `H_p = K_off·H_q`，全屏蔽应让该层**退化为恒等**（`H' = H`）→ 整网 = **A1（S-Mamba + FreDF）**，比 S-Mamba 好。所以**最差不会与 S-Mamba 持平，下界是 A1**（ETTh1-96：A1 0.3757 vs S-Mamba 0.3877）。
- **实际**：γ=0.1 时全屏蔽只 +0.80%（≈ A1 ✓ 符合理论）；**γ=1.0 时全屏蔽 +108%**。
- **原因**（`qcc/quantum_mix.py`，raw_k 分支之后）：
  ```python
  _h   = self.ln(Hp)        # self.ln = nn.LayerNorm(d_token)
  Hp_g = self.hp_scale * _h
  return H + γ * Hp_g
  ```
  `K_off` 全零 → `Hp = 0` → **`LayerNorm(0) = β`（可学习偏置，不是 0）** → 每层被加上 `γ·β` 这个常向量；γ=1.0、两层叠加 → 表示被推离 → 误差翻倍。**这是实现假象，不是"耦合被去掉"。**
- **`RENORM` 是死的**：raw_k 分支（`:525`）**没有重归一化代码**（只有 softmax 分支有），所以 `RENORM=0/1` 跑出的数一字不差。
- **排序本身有效**：75% 时 移除最强 +58.96% vs **随机 +8.36%** vs 移除最弱 +14.90%（差 7 倍）；但 50% 时反过来（最强 +3.44% < 最弱 +4.37%），不稳。
